# 7D2D POI Editor

A Windows editor for 7 Days to Die POIs (prefabs). You will be able to open a POI from the game or a mod, change it, or build a new one, outside the game. The editor reads and writes the game's own prefab files, so no mod is needed: `.tts` (blocks), `.blocks.nim` (block names), `.xml` (properties, sleeper volumes, markers) and `.ins`.

Game assets (blocks, shapes, textures) are read from your own install and never shipped with the editor. This is a fan-made tool and is not made by or affiliated with The Fun Pimps.

## Status

The editor is in development and there is no release yet. To hear when the first one is out, use **Watch > Custom > Releases** at the top of this page.

What changed in each version will be in the [changelog](CHANGELOG.md).

## Requirements

- Windows 10 or 11 (64-bit)
- A copy of 7 Days to Die (v3.4)
